# دليلي ليبيا — Dalili Libya

«طريقك واضح، وين ما تمشي في ليبيا»

تطبيق أندرويد حقيقي للملاحة بين المدن الليبية.

## ما هو حقيقي فعلًا

- **خريطة ثلاثية الأبعاد**: MapLibre GL (داخل WebView أصلية في التطبيق) بخريطة OpenStreetMap، مع طبقة مبانٍ مجسّمة (fill-extrusion) وإمالة للعرض.
- **مسارات حقيقية**: خدمة OSRM العامة (router.project-osrm.org) على بيانات OpenStreetMap، مع بدائل ومسافة ووقت.
- **مدن ليبيا**: قاعدة مدن مدمجة بإحداثيات تقريبية لمراكز المدن، تُستخدم لالتقاط أقرب طريق.
- **GPS**: نقطة انطلاق من موقعك الحالي بعد إذن الموقع.
- **ملاحة صوتية عربية**: Android TextToSpeech بالعربية، خطوة بخطوة من خطوات OSRM.
- **بلاغات طرق محلية**: زحام، حادث، صيانة، إغلاق، طريق ترابي، محفوظة محليًا على الجهاز.
- **محطات وقود**: بحث Nominatim عن محطات قريبة من منتصف المسار، مع رسالة واضحة إذا لم توجد نتائج في بيانات OpenStreetMap.

## ما هو معاينة أو تقدير، وليس بيانات مباشرة مؤكدة

- **العرض "4D"**: معاينة زمنية متحركة على المسار عبر شريط التمرير، وليست بيانات زحام مباشرة لكل الطرق الليبية. لا توجد بيانات زحام مباشرة موثوقة لكل الطرق الليبية من البداية.
- **درجة الأمان**: تقدير من نوع الطريق وعدد بلاغات المستخدمين، وليست تصنيفًا رسميًا للسلامة.
- **تقدير الوقود والتكلفة**: من المسافة واستهلاك قابل للتعديل وسعر تقديري قابل للتعديل، وليس سعرًا رسميًا.
- **البلاغات**: بلاغات مستخدمين محلية، مع وقت آخر تحديث، وليست تأكيدًا رسميًا من جهة مختصة.

## بناء APK حقيقي

يُبنى التطبيق في GitHub Actions عند الدفع إلى فرع `main`، أو يدويًا من تبويب Actions:

1. Checkout
2. JDK 17 (Temurin)
3. Android SDK
4. `assembleDebug` عبر `gradle/gradle-build-action`
5. رفع `app/build/outputs/apk/debug/app-debug.apk` كـ Artifact باسم `dalili-libya-debug-apk`

لا حاجة لمفتاح API للخريطة أو للمسارات في هذه النسخة، لأنها تستخدم مصادر مفتوحة عامة.

## ملاحظات تقنية

- لا يوجد `gradle-wrapper.jar` في المستودع؛ سير العمل يستخدم Gradle عبر `gradle-build-action`. للمطورين محليًا، يمكن تشغيل `gradle assembleDebug` بعد تثبيت Android SDK وJDK 17.
- الخريطة تحتاج اتصالًا بالإنترنت لتحميل البلاطات وأسلوب MapLibre من demotiles.maplibre.org في هذه النسخة.
